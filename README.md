# Рой — 60 000 частиц, которые собираются в формы

Сайт вымышленной студии генеративной графики. Пока вы листаете, рой частиц перетекает из сферы в узел, потом в спиральную галактику и в конце складывается в слово «ПРИВЕТ». Частицы расступаются вокруг курсора.

## Как это сделано
- **Three.js + свой GLSL-шейдер:** все 60 000 частиц двигаются на видеокарте, процессор только передаёт прокрутку и мышь
- 5 наборов координат в буферах (разлёт, сфера, узел, галактика, текст), шейдер плавно смешивает их с индивидуальной задержкой для каждой частицы
- Simplex-шум закручивает частицы в вихрь во время перехода
- Слово «ПРИВЕТ» рисуется на скрытом canvas, и частицы встают в его пиксели
- Пост-обработка UnrealBloom даёт свечение
- На телефонах частиц меньше, учитывается `prefers-reduced-motion`
